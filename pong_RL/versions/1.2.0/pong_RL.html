Pong RL — Plain JS

Train the right (blue) paddle with reinforcement learning from interactive experience while the left (red) opponent remains scripted and non-adaptive.

Comparison guide: pong_evolution uses neuroevolution / a genetic algorithm over neural nets. pong_RL uses reinforcement learning, updating one agent from episode-by-episode rewards gathered while it plays.
1.00x 8 ep/s
What is an episode? One episode is a full Pong rally session from reset until either paddle reaches the target score or the frame budget is exhausted. After the episode, the blue agent updates its Q-values from the rewards it experienced.
Red paddle: scripted opponent (fixed rule, no learning).
Blue paddle: RL agent (tabular Q-learning over discretized game state).
Reward chart blue: episode reward.
Reward chart orange: moving average reward.
Learning chart green: exploration rate epsilon.
Learning chart purple: policy update count.
